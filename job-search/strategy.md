## Strongest job categories (current ranking)

Re-ranked 2026-09-26 to stop leading with Flutter (one project skill, not the headline) and to weight roles less exposed to AI automating narrow app-coding work.

1. **Technical Sales Engineer / Solutions Engineer / Solutions Consultant** — relationship- and trust-dependent work; can demo and explain a real shipped product end-to-end; speaks four languages. No proven sales experience — tailor hard, don't mass-apply.
2. **DevOps / Release & Platform Engineering** — ran Barruu's entire release pipeline solo (signing, versioning, staged rollouts); real CI/CD and Git experience. Gap: no Docker/Kubernetes/Terraform evidence yet — target junior/graduate-programme postings, not ones wanting hands-on infra experience.
3. **Systems / Backend Engineer (generalist)** — CS depth across Java, C/C++, Python, SQL, Dart from a rigorous 4-year engineering program, not tied to one framework.
4. **Junior / Graduate Software Engineer (generalist)** — strong degree, a genuinely shipped product, language breadth.
5. **Full-Stack / Mobile Product Engineer (Flutter, React, Firebase)** — still the best concrete proof of shipping solo; use as evidence, not as the target title.
6. **AI / ML / NLP** — one real, specific 3-month internship; a differentiator, not a standalone target.

Pending decision: whether to reference the Tigi/narogram AI-agent governance framework (a separate large project, built mostly by AI agents under a self-designed oversight process) — potentially the strongest evidence yet for "durable in an AI-heavy industry," but needs explicit sign-off before use in any application.

## Roles to avoid / deprioritize

- Senior/mid-level roles requiring 3+ years of production experience (real non-academic experience is closer to ~7 months).
- Backend-heavy Java/Spring/microservices roles expecting hands-on framework experience.
- Senior/infra-heavy DevOps/SRE roles wanting hands-on Kubernetes/AWS/Terraform.
- Production ML / Data Engineer roles (the NLP work is research/training-focused, not pipelines/infra).
- Native iOS (Swift) or native Android (Kotlin) specialist roles — all mobile experience is Flutter/Dart.
- Quota-carrying Account Executive sales roles (different skillset than Solutions Engineering).

## Geographic strategy

1. **Romania (Bucharest)** — no relocation friction, degree recognized locally.
2. **Remote-from-Romania** — still governed by Romanian immigration rules regardless of employer location; the real question per posting is whether the employer can use a Romanian entity or Employer-of-Record.
3. **Wider EU/EEA** — realistically needs a fresh visa process per country; watch for Germany's 2026 Blue Card reform, which lowered the threshold specifically for recent graduates (~€45,934/year), and Netherlands' real Flutter/tech hiring volume.
4. **Canada / USA** — long shot right now: real search via Dice (US) and ZipRecruiter (Canada) turned up almost nothing entry-level that also offers fresh sponsorship; most "willing to sponsor" US listings assume the candidate already holds US work authorization (H-1B/OPT/GC-EAD).

Given the ~9-month job-search permit window, Tiers 1–2 carry the near-term volume; Tier 3 is worth it specifically where a posting names Blue Card or graduate relocation sponsorship.

## Process notes

- Match-score policy: 80–100 prioritize, 70–79 apply absent a disqualifier, 60–69 judge case by case, below 60 skip.
- Applications: email-apply roles are sent directly; portal/ATS roles get a full tailored package (CV + note) for manual submission — no browser-automation access exists to submit portal forms directly.
- CV tailoring reorders skills/emphasis per posting; never invents technologies, experience, or metrics not confirmed as true.
